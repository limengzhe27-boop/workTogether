# Codex 参考界面验收（v3）

日期：2026-10-10。用户提供的完整深色截图为主参考，[官方导航示意](https://learn.chatgpt.com/docs/features) 为补充。设计决策见 [DESIGN.md](../../DESIGN.md)。本批只改变前端展示和导航，不改变调度、数据库、团队权限和模型启停。

## 对齐项与有意差异

| 区域 | 实现 |
| --- | --- |
| 页面结构 | 冷灰顶部工作栏、窄工具轨、项目任务树、深色主对话区 |
| 侧栏 | 文件夹层级、缩进任务、灰色选中行、收起/展开、当前项目任务搜索 |
| 消息 | 右侧蓝色用户气泡、真实消息时间、无卡片 Agent 正文、细线身份栏、复制入口 |
| 输入区 | 底部固定、大圆角灰底、多行输入、团队入口、权限说明、接收者选择、圆形发送 |
| 细节 | 统一描边图标、中文字体、弱分隔线、轻动效和减少动态效果支持 |

保留 WorkTogether 品牌、多 Agent 身份、真实阶段操作与审批；没有伪造系统窗控、语音、宠物、上传、未读提示、运行耗时或模型切换。输入区“＋”实际打开团队；下拉项选择消息接收者。主按钮蓝色略微加深以满足正文对比度，不声称逐像素复刻。已完成的浅色版验收记录保留为历史。

## 本机浏览器检查

- 1046×653、1440×900、390×844 均无页面横向溢出。1046 桌面输入框底部 y=633；390 手机输入框底部 y=832，在视口内。
- 桌面收起项目栏后主区扩宽；展开后项目和选中任务保留。对话长历史独立滚动。
- 当前项目搜索能过滤标题、显示无结果，Escape 关闭并归还焦点；搜索输入框打开即聚焦。
- 手机项目抽屉的主区和顶部 inert，焦点进入导航；经抽屉打开搜索后退出，焦点回到顶部导航按钮。手机 Agent 设置可达，保留本机 Harness 配置，未启用任何 Agent。
- 临时输入草稿后切到详情再返回，草稿保留；检查后恢复原内容，未发送。
- 输入框“＋”能打开团队弹窗，Escape 后焦点回到该按钮。
- 复制按钮在浏览器内使用临时剪贴板替身验证：收到正文并显示“已复制”；随后恢复原方法，未读取或覆盖系统剪贴板。真实剪贴板权限拒绝仅作代码路径检查。
- “新建任务”进入需求页并聚焦输入框，连续执行授权默认未选；没有创建真实验收任务。
- “讨论方案”先显示轮数、额度与权限说明，取消不启动模型。
- 历史阻塞任务仍显示失败原因和“查看并处理”入口；没有执行真实重试。

## 边界

本轮没有对真实任务执行发送、授权、批准、运行、启停 Agent 或重试。渲染测试与后端回归不能代替真实多模型闭环测试。本机验收截图含用户历史，不纳入公开仓库；不复制用户截图中的其他项目、账号或聊天文本作为示例数据。

复查时使用上述三个视口；如需验证消息提交或运行流程，应使用隔离数据库与模拟 Agent。字体在线可用时加载 Noto Sans SC，离线回退本机字体，不保证不同系统字形完全相同。
