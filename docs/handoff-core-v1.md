# 给 Antigravity 的第一阶段交接

## 结论

调度核心与 CLI 已实现，可以开始独立黑盒测试。
请以 `docs/contracts/v1.md` 为准，使用 `python3 -m worktogether` 或
`worktogether.core.Engine`。不需要安装本项目依赖。

## 依据

生产目录：`worktogether/`。核心自测：`tests/core/`。
执行：`python3 -m unittest discover -s tests/core -v`。
已有覆盖：正常闭环、重启、并发去重、项目锁、跨任务拒收、版本匹配、
缺证据拒收、单轮审查、循环依赖拒收、两次修复上限、暂停、超时重试。

当前目录最初为空且非 Git 仓库，未擅自初始化版本库。
被测版本请按实际交付文件计算摘要，或待建立仓库后记录提交。

## 已知范围

- 当前是手动/模拟模式，尚未真实调用两个模型。
- Evidence 是 Agent 的声明与引用；程序检查结构，不保证引用内容真实。
- 版本字符串需由执行者提供真实固定版本；没有自动 worktree。
- 重试前应确认旧外部执行停止；没有提供外部进程恰好一次执行保证。
- SQLite 中存 JSON 聚合任务，适用于本地 MVP；没有网页或后台轮询服务。
- BLOCKED 不代表 PASS。暂停只停止派发，允许接收在途结果。

## 下一步

请在分配给你的目录提交黑盒测试及失败证据，尤其检查重叠执行时多个
阻塞的组合、重复消息、暂停边界和格式错误。不要修改生产模块。
失败报告附运行命令、被测文件/版本、预期和实际输出。
